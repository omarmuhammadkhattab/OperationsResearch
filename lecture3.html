LECTURE 03

The Transportation
Problem

A special LP problem: ship goods from m sources (warehouses/factories) to n destinations (markets/stores) at minimum total cost — subject to supply and demand constraints.

01

Mathematical Model

The transportation problem has a special structure: a grid of sources (rows) and destinations (columns). Variable Xij is the quantity shipped from source i to destination j.

Minimize   Total Cost = ΣΣ Cᵢⱼ · Xᵢⱼ   Subject to: Σⱼ Xᵢⱼ = Sᵢ (i = 1…m)   ← Each source ships its entire supply Σᵢ Xᵢⱼ = Dⱼ (j = 1…n)   ← Each destination receives its full demand Xᵢⱼ ≥ 0 for all i, j
BALANCED PROBLEM

Total Supply = Total Demand

When ΣSᵢ = ΣDⱼ, the problem is balanced and has a feasible solution.

UNBALANCED PROBLEM

Add Dummy Row or Column

Supply > Demand → add dummy destination column with 0 costs.
Demand > Supply → add dummy source row with 0 costs.

KEY NUMBERS

Important Quantities

Decision variables in table: m × n  |  Total constraints: m + n  |  Cells to fill (basic feasible solution): m + n − 1

02

Three Solution Methods

These three methods find an initial basic feasible solution. The quality of the initial solution differs — Vogel's usually gives the best starting point.

METHOD 01

North-West Corner

  • Start at top-left (NW) cell X₁₁
  • Allocate min(Supply, Demand)
  • Cross out exhausted row or column
  • Move right or down; repeat
  • Ignores costs — fastest but poorest solution
METHOD 02

Least Cost (Matrix Minima)

  • Find the cell with smallest cost in entire table
  • Allocate min(Supply, Demand) to that cell
  • Cross out exhausted row/column
  • Repeat for remaining cells
  • Considers costs — better than NW Corner
METHOD 03

Vogel's Approximation (VAM)

  • Compute penalty = 2nd smallest − smallest cost in each row/column
  • Select row/column with largest penalty
  • Allocate to the cheapest cell in that row/col
  • Re-calculate penalties and repeat
  • Best initial solution — closest to optimal

04

Solution Improvement (MODI Method)

The initial solution from any method may not be optimal. The MODI (Modified Distribution) Method checks if the current solution can be improved.

1
Assign U/V values to non-empty cells: For each occupied cell (i,j), solve Uᵢ + Vⱼ = Cᵢⱼ. Set U₁ = 0 and solve for all others.
2
Calculate improvement index for empty cells: For each empty cell: Zᵢⱼ = Uᵢ + Vⱼ − Cᵢⱼ. If all Zᵢⱼ ≤ 0, solution is optimal.
3
Find the entering cell: The empty cell with the most positive Zᵢⱼ value enters the solution.
4
Form a loop (closed path): Starting from the entering cell, trace a path (+, −, +, −…) through occupied cells. Add the smallest "−" cell value to all "+" cells, subtract from all "−" cells. The "−" cell that becomes 0 leaves the basis.
✓
Optimality: Repeat until no positive Zᵢⱼ values remain in empty cells.
Non-empty cells:   Uᵢ + Vⱼ = Cᵢⱼ Empty cells:      Zᵢⱼ = Uᵢ + Vⱼ − Cᵢⱼ Optimality:      All Zᵢⱼ ≤ 0 for empty cells
05

Method Comparison

MethodProcedureSolution QualitySpeedComplexity
NW Corner Always go top-left, then right/down Poor (ignores costs) Fastest Easy
Least Cost Always pick cheapest available cell Better (cost-aware) Medium Medium
Vogel's (VAM) Compute penalties, pick largest Best (near-optimal) Slower Complex
Remember: All three methods give an initial feasible solution. To find the true optimum, apply the MODI (solution improvement) method afterward. Often, Vogel's initial solution is already optimal or requires fewer MODI iterations.
