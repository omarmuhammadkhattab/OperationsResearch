01

The Graphical Method

The graphical method applies to LP problems with exactly two decision variables. It works by plotting all constraints on a 2D plane to find the feasible region — the set of all points that satisfy every constraint simultaneously.

KEY THEOREM

Corner Point (Extreme Point) Theorem

The optimal solution to a linear program always occurs at one of the corner points (vertices) of the feasible region. We simply evaluate the objective function at every corner and pick the best value.

1
Plot each constraint as an equality. Set the constraint to "=" and find two points (set x=0, find y; set y=0, find x). Draw the line.
2
Identify the feasible region. For ≤ constraints, shade toward the origin. For ≥ constraints, shade away from the origin. The feasible region is the intersection of all shaded areas.
3
Find all corner points. Corner points are where constraint lines intersect each other or the axes. Solve pairs of equations simultaneously.
4
Evaluate Z at each corner. Substitute each corner point into the objective function. For maximization: pick the largest Z. For minimization: pick the smallest Z.

03

The Simplex Method

The Simplex method handles LP problems with any number of variables. It moves systematically from one corner of the feasible region to a better adjacent corner, always improving the objective value until the optimum is reached.

STANDARD FORM

Converting ≤ Constraints to Standard Form

Add a slack variable (S₁, S₂, …) to each ≤ inequality to convert it to an equality. Slack variables represent unused resources. Their objective coefficient is 0.

Original Model:
Max Z = 3X₁ + 5X₂
3X₁ + 2X₂ ≤ 18, X₁ ≤ 4, X₂ ≤ 6

Standard Form (add S₁, S₂, S₃):
Max Z = 3X₁ + 5X₂ + 0S₁ + 0S₂ + 0S₃
3X₁ + 2X₂ + S₁ = 18
X₁ + S₂ = 4
X₂ + S₃ = 6
X₁, X₂, S₁, S₂, S₃ ≥ 0

Simplex Iteration Rules

1
Find the Entering Variable: In the Zⱼ − Cⱼ row, pick the column with the MOST NEGATIVE value. That column's variable enters the basis.
2
Find the Leaving Variable: Divide each RHS value by the corresponding positive element in the entering column. The row with the SMALLEST RATIO identifies the leaving variable.
3
The Pivot Element: The intersection of entering column and leaving row is the PIVOT. Divide that entire row by the pivot value to make it equal to 1.
4
Row Operations: Use the new pivot row to eliminate the entering variable from all other rows (including Z row) using: New Row = Old Row − (factor × Pivot Row). Repeat until no negatives remain in Z row.
✓
Optimality Check: When all values in Zⱼ − Cⱼ row are ≥ 0, the current solution is optimal. Read the solution from the RHS column.
