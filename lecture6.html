Key Formula
Project Cost

Each activity of the project consumes resources and therefore has a cost associated with it. In most cases the cost of an activity varies with the amount of time consumed. The total project cost — the aggregate of all activity costs — therefore also depends on project duration.

The aim is always to strike a balance between cost and time and obtain an optimum project schedule — the one with the lowest possible total cost and its associated completion time.

Direct Cost

Directly dependent on the resources used to execute individual activities: materials, equipment, and labour. Direct cost decreases as project duration increases (more time = less overtime, fewer extra resources).

Indirect Cost

Overhead not tied to specific activities. Sub-divided into fixed and variable indirect costs. Indirect cost increases as project duration increases (more time = more overhead).

Total Cost

Sum of direct and indirect costs. The optimum project duration is where total cost is minimised — the bottom of the U-shaped total-cost curve.

// TIME–COST TRADE-OFF CURVE

Project Crashing

Project crashing is a method for shortening project duration by reducing the time of one or more critical activities to less than their normal duration — at an additional cost. The decision is based on analysis of the trade-off between time and cost.

Cost Slope — additional cost per unit of time saved Cost Slope (S) = (Crash Cost − Normal Cost) / (Normal Time − Crash Time)
i.e. S = (CC − NC) / (ND − CD)
Steps in Project Crashing
1
Identify the critical path and the critical activities using CPM.
2
Determine the cost slope for each activity using the formula above.
3
Crash the critical activity with the minimum cost slope. Calculate the new direct cost by adding the crashing cost to the normal cost.
4
As crashing proceeds, non-critical activities may become critical, creating multiple critical paths. If so, choose one activity from each such path for crashing.
5
Of all available combinations, select the one with the least combined cost.
6
Revise the network with updated durations and costs. Re-identify the critical path(s).
7
Continue until no further crashing is possible. Calculate total crash cost (normal direct cost + additional crash cost + indirect cost).
8
Prepare the total cost table for different project durations.
9
The minimum total cost is the optimum cost and its associated duration is the optimum time.

Key Takeaways
Always crash critical activities

Only critical activities affect project duration. Crashing non-critical activities wastes money without reducing time.

Choose minimum cost slope first

Always crash the critical activity with the flattest slope (least additional cost per unit time saved).

Watch for new critical paths

After each crash, re-identify critical paths. Multiple simultaneous critical paths require crashing one activity from each to reduce overall duration.

Optimum schedule minimises total cost

As you crash, build a cost table for each duration. The minimum total cost (direct + indirect) gives the optimum schedule.
