LECTURE 04

The Assignment
Problem

Assign n workers to n jobs to minimize total cost. A special case of transportation where each supply and demand equals 1. Solved elegantly with the Hungarian Algorithm.

01

Problem Formulation

Given n jobs and n persons (workers/machines), where Cij is the cost of assigning person i to job j. We want to minimize total assignment cost.

Minimize   Z = ΣΣ Cᵢⱼ · Xᵢⱼ
Subject to:
  Σᵢ Xᵢⱼ = 1  for j = 1…n   (each job done by exactly one person)
  Σⱼ Xᵢⱼ = 1  for i = 1…n   (each person does exactly one job)
  Xᵢⱼ ∈ {0, 1}               (binary: assigned or not)
KEY PROPERTY

Relationship to Transportation Problem

The assignment problem is a transportation problem where every supply Sᵢ = 1 and every demand Dⱼ = 1. The special structure allows the elegant Hungarian Method, which is far more efficient than general LP or transportation algorithms.

02

The Hungarian Algorithm

The key insight: subtracting a constant from any row or column does not change the optimal assignment (only the total cost changes). We reduce costs until zeros appear in a pattern that reveals the optimal assignment.

Subtract Row Minima

For each row, find the minimum element. Subtract it from every element in that row. This creates at least one zero per row.

Subtract Column Minima

For each column, find the minimum element. Subtract it from every element in that column. This creates at least one zero per column.

Cover All Zeros

Find the minimum number of horizontal and vertical lines needed to cover all zeros. If this number equals n → go to Step 5 (optimal found!). Otherwise go to Step 4.

Create Additional Zeros

Find the smallest uncovered element (call it k). Subtract k from all uncovered elements. Add k to elements covered by two lines. Return to Step 3.

Assign Optimal Cells

Select zeros so that each row and each column has exactly one selected zero. These positions give the optimal assignment. Calculate total cost from the original matrix.
