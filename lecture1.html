01

What is Operations Research?

Operations Research (OR) is a quantitative approach to decision making based on the scientific method of problem solving. It applies mathematical and statistical methods to help organizations make better decisions.

The research process follows a clear pipeline: identify the situation → state the problem → construct a model → validate it → experiment → find candidate solutions.

DEFINITION

Linear Programming (LP)

LP deals with the optimization (maximization or minimization) of a function of variables — called the objective function — subject to a set of linear equalities and/or inequalities called constraints.

02

Structure of an LP Model

Every LP model has exactly three components. Without all three, the model is incomplete.

① Decision Variables

The unknowns we want to find — the quantities we control. Usually denoted X₁, X₂, X₃ or A, B, X, Y. Each variable represents something we're deciding how much of: units to produce, hectares to plant, hours to schedule, etc.

② Objective Function

  • A linear function of the decision variables
  • Either Maximize (profit, revenue, output)
  • Or Minimize (cost, waste, time)
  • Written as: Max/Min Z = c₁x₁ + c₂x₂ + …

③ Constraints

  • Linear inequalities or equalities limiting the variables
  • Resource limits, demand caps, capacity bounds
  • Always include non-negativity: X₁, X₂ ≥ 0
  • Written as: aX + bY ≤ RHS
Max Z = c₁X₁ + c₂X₂ + c₃X₃
S.T.
a₁₁X₁ + a₁₂X₂ + a₁₃X₃ ≤ b₁  (Resource 1)
a₂₁X₁ + a₂₂X₂ + a₂₃X₃ ≤ b₂  (Resource 2)
X₁, X₂, X₃ ≥ 0                 (Non-negativity)
03

Key Rules for Formulation

When reading a word problem, look for these signal words to know what type of constraint or objective to write:

🎯 Objective Function

  • Profit / Revenue / Income → Maximize
  • Cost / Expense / Loss → Minimize

📐 Constraint Direction

  • Budget / Maximum / At most / Capacity / Restricted → ≤
  • Minimum / At least / Not less than / More than → ≥
REMEMBER

Non-Negativity Constraint

Always add X₁, X₂, … ≥ 0 to every LP model. Physical quantities (units produced, hours worked, etc.) cannot be negative. This constraint defines the feasible region to the positive quadrant.

3-STEP FORMULATION PROCESS

How to Always Solve Formulation Problems

Step 1: Read carefully and define your decision variables — what are you choosing?
Step 2: Identify all constraints — what limits your choices? (resources, demands, capacities)
Step 3: Write the objective function — what are you trying to optimize?
